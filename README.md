# 💍 Eternal Bond – Digital Wedding Album SaaS

A modern **SaaS-based Digital Wedding Album Platform** built using **Spring Boot**, **PostgreSQL**, and **Flutter Web**.

This platform allows photographers or wedding clients to:

- Create wedding albums
- Upload wedding photos
- Add background music
- Generate QR codes
- Share albums using public URLs
- View albums in a beautiful Flipbook-style digital experience

The system works like a professional **E-Wedding Album Generator** for photographers and studios.
